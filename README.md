## пис проєкту
`HuffmanLib` — це статична бібліотека мовою C++20 для стиснення та відновлення текстових даних за допомогою алгоритму адаптивного кодування Хаффмана.

Проект демонструє:
- Створення власної ієрархії винятків (`HuffmanException` та похідні класи).
- Забезпечення **Сильної Гарантії Безпеки Винятків** (Strong Exception Guarantee) за принципом *prepare-then-commit* у методі `buildTree()`.
- Застосування концепції **RAII** та механізму розкручування стека (Stack Unwinding) за допомогою класу `ScopeLogger`.
- Автоматизоване модульне тестування на базі фреймворку **Google Test**.
- Демонстрацію антипатернів обробки винятків (примітивні типи, Object Slicing).

Збирання та запуск проєкту
Вимоги:
Компілятор з підтримкою C++20 (MSVC / GCC / Clang)

CMake 3.21 або новіше

Visual Studio 2022 (рекомендовано)

Запуск через Visual Studio:
Відкрийте папку проєкту у Visual Studio (Файл -> Открыть -> Папка).

Дочекайтеся завершення конфігурації CMake та завантаження Google Test.

Оберіть необхідну ціль для запуску:

HuffmanDemo.exe — демонстрація розкручування стека.

HuffmanTests.exe — запуск модульних тестів Google Test.

AntipatternDemo.exe — демонстрація антипатернів.

Натисніть F5 або зелену кнопку запуску.

Результати тестування
